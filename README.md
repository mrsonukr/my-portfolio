# My Portfolio  
A fully animated and interactive portfolio website built with modern web technologies.  

## 🔥 Features  
- 🚀 Smooth animations and transitions  
- 🎨 Fully responsive design  
- 📜 Dynamic content sections  
- 📱 Optimized for all devices  
- ⚡ Fast loading speed  

## 🛠️ Tech Stack  
- **Frontend:** HTML, CSS, JavaScript (or React, GSAP, Three.js)  
- **Animations:** GSAP, CSS Animations, Framer Motion  
- **Hosting:** GitHub Pages / Vercel / Netlify
